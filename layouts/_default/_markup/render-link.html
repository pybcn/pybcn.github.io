{{- /* Link render hook. Content used to write raw to open an external site in a new tab. Those were converted to plain markdown links, so the behavior has to come from here. The raw ones would still render, because unsafe=true is set in [markup.goldmark.renderer] in config.toml for the two pre-Hugo programs pasted in as tables, but no new content writes an anchor of its own. An external link gets target="_blank" and rel="noopener noreferrer". The rel part is new: target="_blank" on its own hands the opened page a window.opener handle to this one, which is a reverse tabnabbing path. A relative link, an anchor, a mailto: link and a link back to this site keep the default behavior and open in the same tab. */ -}} {{- $url := urls.Parse .Destination -}} {{- $external := and $url.Host (ne $url.Host (urls.Parse .Page.Site.BaseURL).Host) -}} {{- /* The attributes are written by the template, not assembled with printf and emitted through safeHTMLAttr. Go's %q is shell-style quoting, not HTML escaping: a quote in a link title came back as \" , which closes the attribute early and leaves the rest of the title as stray attribute names. */ -}} {{- /* An external link in the body of a page carries the same mark as one a template writes, through partials/link_mark.html: every link that leaves this site says where it goes. The gap showed on the page of PyData Barcelona 2017, whose body links a YouTube playlist and a Flickr album, and neither had a mark: the marks had reached the templates and not the prose. */ -}} {{ if $external }}{{ partial "link_mark.html" .Destination }}{{ end }}{{ .Text }}
