{{- /* A grid of sponsor logos, one band per level. Every card is the same size and every logo sits in the same fixed box inside it, so no sponsor reads as having paid for a bigger slot. What responds to the width of the window is the number of cards on a line, not the size of a logo: a logo that is scaled by the viewport is a logo that is unreadable on a phone and enormous on a desktop. The columns were Bootstrap ones, col-md-{12 / sponsors_per_line}, and with a fixed card height inside them the cells overlapped and left holes. The row is a CSS grid now and the cards are its items, so the browser lays them out and nothing can overlap. sponsors_per_line is the cap a named level asks for, which is what an edition page uses to say that its two Gold sponsors are bigger news than its eight Supporting ones. A level that asks for nothing, which is /sponsors/, fills the line with as many cards as fit. The cap travels as a class and not as an inline custom property, because bin/check-rendered refuses an inline style the stylesheet could carry: sponsors.scss writes one rule per value, and the data holds 2, 3 and 4. The row ids carry the "sponsors" prefix so that they cannot collide with the rows of a people grid on the same event page. */ -}}
