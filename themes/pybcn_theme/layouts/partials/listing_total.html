{{- /* The number of rows a listing page draws, or 0 for any other page. Argument: the page. Returns an int. Three pages are a list of the whole archive: /events/, /talks/, and /people/. Their h1 carries the total, and this is where the page is told apart from the rest. /events/ is the one page that selects the events_index layout; the series pages under it are sections of the same section and keep the fallback list. /talks/ and /people/ are the section page of a section that holds no other section, so the kind and the section name are enough. The page of one type of talk, /talks/type/workshop/, is a view of the talks listing (content/talks/_content.gotmpl adds it, with the token as params.filter), and its h1 carries the rows of that view, "Talks: Workshops (172)", the count its tab reads from the same map. The page of one role, /people/role/speaker/, is the same for the people listing (content/people/_content.gotmpl, partials/people_index.html): "People: Speaker (358)". A view with no rows, Attendees, gets 0 and so no count in its h1, which is the fact. The totals come from partials/listing_counts.html, cached once per build, and are counted by the rule of the page that draws the rows: the legend of the page, the heading above it, and the rows add up. */ -}} {{- $total := 0 -}} {{- $listing := "" -}} {{- if eq .Layout "events_index" -}} {{- $listing = "events_total" -}} {{- else if and (eq .Kind "section") (eq .Section "talks") -}} {{- $listing = "talks_total" -}} {{- else if and (eq .Kind "section") (eq .Section "people") -}} {{- $listing = "people_total" -}} {{- end -}} {{- /* A sponsors page counts the logos it is about to draw, from its own declared levels when it has them and from the directory when it does not, so "Sponsors (71)" and "PyLadies BCN Sponsors (18)" each say the number of their own grid. Not through listing_counts.html, because the two pages draw different sets. */ -}} {{- if eq .Layout "sponsors" -}} {{- with .Params.sponsor_levels -}} {{- range . -}}{{- $total = add $total (len (.sponsors | default slice)) -}}{{- end -}} {{- else -}} {{- $total = len (partial "sponsor_ids.html" site) -}} {{- end -}} {{- end -}} {{- with $listing -}} {{- $total = index (partialCached "listing_counts.html" site "listing-counts") . -}} {{- end -}} {{- if and (eq .Kind "page") (eq .Section "talks") .Params.filter -}} {{- $total = int (default 0 (index (partialCached "listing_counts.html" site "listing-counts").talks .Params.filter)) -}} {{- end -}} {{- if and (eq .Kind "page") (eq .Section "people") .Params.filter -}} {{- $total = int (default 0 (index (partialCached "people_index.html" site "people-index").labels .Params.filter)) -}} {{- end -}} {{- return $total -}}
