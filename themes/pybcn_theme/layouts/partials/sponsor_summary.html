{{- /* One sponsor logo, linked to the sponsor site. Logos come from assets/images/sponsors/ and go through the Hugo image pipeline. The grid caps a logo at 150 px high, so a 560 px WebP covers the widest slot, with a 1120 px variant for a 2x screen. Two cases stay unprocessed: an external logo URL, because Hugo cannot process a remote file; and an SVG, which needs no raster step. A GIF goes through the pipeline too, which keeps only its first frame. That is on purpose: an animated logo loops without a pause control, and WCAG 2.2.2 requires one for any motion that lasts more than five seconds next to other content. A sponsor logo is decoration, so the still frame is the right rendering. Put the brand in the first frame of any animated GIF. A sponsor with no usable logo shows its name as text, and a sponsor with no web address is not wrapped in an empty link. A broken image reads as a mistake, and an organisation that supported the event deserves better than looking like a missing asset. */ -}} {{- $sponsor := $.sponsor -}} {{- $name := $sponsor.Params.name | default $sponsor.Params.id -}} {{- $src := $sponsor.Params.logo -}} {{- $srcset := "" -}} {{- $width := 0 -}} {{- $height := 0 -}} {{- if not $src -}} {{- with resources.Get (printf "images/sponsors/%s" $sponsor.Params.logo_image) -}} {{- if eq .MediaType.SubType "svg" -}} {{- $src = .RelPermalink -}} {{- else -}} {{- $small := .Fit "560x150 webp q80" -}} {{- $large := .Fit "1120x300 webp q80" -}} {{- $src = $small.RelPermalink -}} {{- $width = $small.Width -}} {{- $height = $small.Height -}} {{- if gt $large.Width $small.Width -}} {{- $srcset = printf "%s 1x, %s 2x" $small.RelPermalink $large.RelPermalink -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- /* The markup is written out in both branches instead of being assembled into a string. Building it with printf and emitting it through safeHTML would put the sponsor name and logo URL into the page unescaped, which is an injection route through a pull request from outside. Go's autoescaping only works when the template writes the attributes itself. */ -}} {{- define "pybcn_sponsor_logo" -}} {{- if .src -}} {{- else -}} {{ .name }} {{- end -}} {{- end -}} {{- $logo := dict "src" $src "srcset" $srcset "width" $width "height" $height "name" $name -}} {{- with $sponsor.Params.web -}} {{- template "pybcn_sponsor_logo" $logo -}} {{- else -}} {{- template "pybcn_sponsor_logo" $logo -}} {{- end -}}
