{{- /* The pages each organizer appears on, inverted from the pages themselves. Returns a map from person id to a list of appearances, each a dict with label, title, url and year. No argument is read: the data comes from site.RegularPages and from data/roles.yaml. Call it through partialCached with a constant variant, so the site is walked once per build and not once per modal: partialCached "appearances_index.html" site "appearances-index" Two front matter shapes list people. An event page has people_sections, each with a title and a list of levels; the section title is the heading. An association page has people_levels, each with a name; the level name is the heading. A level entry is a bare id, or a map with an id when the page overrides the role for that entry (see people-grid.html). Only the people listed on /pybcn_association/organizers/ are indexed. Every other person is a speaker or a volunteer of one event, whose modal would list that one event and nothing else. The Archive will widen this. The heading goes through data/roles.yaml, which turns "Speakers" into "Speaker". The heading itself is the fallback, so a new heading shows up unmapped rather than not at all. An appearance is one (heading, page) pair. Ferran Jovell is listed under two levels of one section of the Django page, Mentors and Speakers, and the modal would otherwise link that page twice under one label. Drafts are skipped by name as well: site.RegularPages drops them in a normal build, but a server run with -D would index content/canary.md. */ -}} {{- $scope := dict -}} {{- with site.GetPage "/pybcn_association/organizers" -}} {{- range .Params.people_levels -}} {{- range .people -}} {{- $id := . -}} {{- if reflect.IsMap . }}{{ $id = .id }}{{ end -}} {{- $scope = merge $scope (dict $id true) -}} {{- end -}} {{- end -}} {{- end -}} {{- $index := dict -}} {{- range $pg := site.RegularPages -}} {{- if $pg.Draft }}{{ continue }}{{ end -}} {{- /* heading -> list of ids, in the order the page lists them */ -}} {{- $headings := slice -}} {{- range $pg.Params.people_sections -}} {{- $ids := slice -}} {{- range .levels }}{{ range .people }}{{ $ids = $ids | append . }}{{ end }}{{ end -}} {{- $headings = $headings | append (dict "heading" .title "ids" $ids) -}} {{- end -}} {{- range $pg.Params.people_levels -}} {{- $headings = $headings | append (dict "heading" .name "ids" .people) -}} {{- end -}} {{- if not $headings }}{{ continue }}{{ end -}} {{- $seen := dict -}} {{- range $headings -}} {{- $heading := .heading -}} {{- $label := default $heading (index site.Data.roles $heading) -}} {{- range .ids -}} {{- $id := . -}} {{- if reflect.IsMap . }}{{ $id = .id }}{{ end -}} {{- if not (index $scope $id) }}{{ continue }}{{ end -}} {{- $key := printf "%s|%s" $label $id -}} {{- if index $seen $key }}{{ continue }}{{ end -}} {{- $seen = merge $seen (dict $key true) -}} {{- $entry := dict "label" $label "title" $pg.Title "url" $pg.RelPermalink "year" (int (default 0 $pg.Params.year)) -}} {{- $index = merge $index (dict $id (append $entry (default slice (index $index $id)))) -}} {{- end -}} {{- end -}} {{- end -}} {{- return $index -}}
